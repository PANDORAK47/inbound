# 팔레트 입고 카운터

## 목적
하차 시 카메라로 팔레트를 상품별 인식·카운트. 전도(넘어짐)는 사진 증빙.

## 구조 (한 줄)
카메라 → AI 인식(또는 바코드) → **카운트 규칙** → 입고 기록 → 요약/CSV

## 핵심 결정
| 결정 | 이유 |
|---|---|
| 웹앱(설치 없음) | 맥북·휴대폰 공용, 링크만 열면 됨 |
| AI는 기기 안에서 실행 | 영상 외부 전송 없음, 서버 비용 0 |
| 현장 사진 30장으로 학습 | 상품이 바뀌어도 개발자 없이 추가 |
| 시간 기준 카운트 규칙 | 0.8초 보이면 +1, 1.2초 비면 다음 |
| 바코드 모드 병행 | 외관 비슷한 상품은 AI보다 정확 |
| 전도는 수동 기록 | 자동 감지는 오탐 위험 → 사진으로 증빙 |

## 알려진 한계
- 같은 상품이 간격 없이 연속 통과 → 1개로 셀 수 있음
- 외관 동일 상품 → 바코드 모드 필요
- 조명·위치 변경 시 재촬영

## 다음 단계 후보
- 실제 하차장 영상으로 정확도 측정
- 여러 기기 기록 통합(서버/DB) — 필요 시
- WMS·ERP 연동(CSV → API)
