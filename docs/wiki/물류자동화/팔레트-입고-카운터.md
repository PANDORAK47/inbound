# 팔레트 입고 카운터

## 결론 (조사 기반)
- 수량 카운트: 가능. 단 도크 팔레트 계수 정확도의 독립 검증 자료는 없음 → 자체 측정 필요
- 상품 식별: **라벨(GS1 GTIN) + ASN(SSCC 대조)** 이 핵심. 외관 AI는 보조
- 상용 시스템(Vimaan·Kargo 등) 99%대 주장은 모두 업체 주장
- 휴대폰 브라우저: "팔 길이에서 라벨 비추는 검수 보조" 까지가 현실적

## 구조
카메라 → (AI 외관 + 바코드 라벨) → 카운터 → 팔레트별 근거 묶음 → 확정 / 확인 필요 → 기록

## 식별 순서
1. GTIN 일치 → 자동 확정
2. SSCC + 입고 예정 → 확정, 중복 SSCC 제외
3. AI 외관 (입고 예정 상품 중에서만)
4. 애매·불일치·예정 외 → 사람 확인 → 확정 사진은 AI 학습에 추가

## 현장 기능
- 하단 탭(작업/확인/상품/기록), 현장 모드(전체 화면·큰 버튼)
- 팔레트별 증빙 사진, 전도 기록, 예정 대비 과부족
- 홈 화면 설치·오프라인(PWA), 손전등
- 검증 지표: 라벨 판독률·자동 확정률·사람 확인 비율·처리 ms

## 한계
